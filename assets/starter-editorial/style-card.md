# 网站风格卡

本地持续维护，不随静态网站导出。本站采用编辑式风格档（starter-editorial），视觉语法见技能目录 references/style-editorial.md。

- 客户希望传达的印象：可靠、有实力、克制；按客户资料与沟通修正
- 参考网站及喜欢的部分：极简编辑式，大留白、真实摄影、发丝线分区
- 配色、字体、间距、圆角：白底近黑单色系；--accent 起始为近黑，有品牌色时替换且仅用于按钮、链接、eyebrow；间距取 8 的倍数；圆角 ≤2px
- 图片风格及使用边界：只使用客户采用或授权的素材；产品、工厂、证书必须实拍；氛围图可生图并记入 facts.md
- 页面布局与组件偏好：编辑式区块模式；列表页保持信息密度，只沿用色彩、字体、细线变量
- 客户反馈与已采用调整：暂无

## 本站设计方案

- 风格档：编辑式 editorial
- 版式与区块模式：首页节奏 = 分栏 Hero → 数字信任条 → 交替分栏（关于）→ 图组条 → 全出血氛围带 → 精选产品 → 合作流程 → 新闻行 → 资质（soft 底）→ 大字 CTA；按资料多缺增删，缺的整段条件渲染
- 品牌色到 CSS 变量的映射：--ink #141414、--body #4a4a4a、--muted #8a8a8a、--accent #141414（待品牌色）、--line #e5e3de、--soft #f6f5f2
- 字体层级与间距：系统黑体，仅 400/700 两种字重；h1 clamp(34px,6vw,60px)、h2 clamp(24px,3.5vw,36px)、正文 16px/1.8；段落间距 96–128px，移动端 64–72px
- 组件清单：极简导航（发丝线压底）、按钮（黑底白字仅一种）、发丝线数字条、极简产品卡（细边框无阴影）、编号步骤行、新闻行、证书墙 / hairline 资质列表、深色页脚

每次修改记录影响后续设计的结论即可，不建立评分或审批流程。
