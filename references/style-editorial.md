# 编辑式设计语言（editorial）

适用气质：制造业、外贸、想传达"可靠、有实力、克制"的企业站。参考特征：近乎单色、摄影供色、大字层级、发丝线分区、大留白。本规范与模板规范并行：模板规范的强制检查不变，本文档约束的是视觉决策。

## 适用边界

- **展示页适用**：首页、关于、联系、详情页。**列表页不适用**——列表必须保持信息密度（循环全部、分页、分类），只沿用本规范的色彩、字体、细线变量。
- **图片前提**：此风格七成效果来自摄影质量。采用前在 PRD 阶段核对图片清单：hero 产品图 ×1、工厂/车间 ×3–4、氛围图 ×1、产品图 ×N、证书 ×N。缺口决定降级程度，客户照片严重不足时建议改用经典卡片风格。

## 十条语法

1. **近乎单色，摄影供色**。底色白，文字近黑，强调色只用于按钮、链接、eyebrow 小标签。页面色彩感来自照片。
2. **字号强对比**。h1 用 `clamp(34px, 6vw, 60px)`、粗字重、行高 1.15；正文 15–16px、行高 1.8、灰色。层级靠尺寸差，不靠色块。
3. **发丝线系统**。分区用 1px `--line`；不用卡片阴影，圆角 ≤4px 或直角。
4. **统一非对称网格**。分栏段落固定文左图右（约 5:5 或 6:4），不左右横跳；节奏靠段落类型变化。
5. **三种全宽节奏带**穿插在文字段落之间：数字信任条、照片连排条、全出血氛围带。相邻两个文字段落之间必须插一条。
6. **编号 + 细横线代替图标卡片**。流程、优势用编号行；不使用彩色装饰图标。
7. **产品卡极简**。细边框、图上文下、名称 + 一行参数，无阴影无按钮堆叠。
8. **大留白**。段落间距 96–128px，内容间距 24–32px；内容列最宽 1200px，正文列 ≤65ch。
9. **大字 CTA + 深色页脚收尾**。导出前一段是全宽大字 CTA；页脚深色反白，把整页压住。
10. **真实摄影压阵**。产品、工厂、证书必须实拍；氛围图可用设计生成的素材，标注来源记入 facts.md。

## 变量基线（theme/assets/site.css）

```css
:root{
  --ink:#141414;        /* 近黑标题 */
  --body:#4a4a4a;       /* 正文灰 */
  --muted:#8a8a8a;      /* 辅助灰 */
  --accent:#141414;     /* 强调=黑；有品牌色时替换并只用于按钮/链接 */
  --paper:#ffffff;
  --soft:#f6f5f2;       /* 浅灰段落底，备用于证书墙等 */
  --line:#e5e3de;       /* 发丝线 */
  --radius:2px;
}
```

间距标尺取 8 的倍数：24 / 32 / 48 / 96 / 128。标题字重 700，正文 400，只用这两种。

## 区块模式与降级

| 模式 | 数据来源 | 无图/无数据降级 |
|---|---|---|
| 分栏 Hero | site.headline、site.extra.intro、hero 图（site.extra 或固定路径） | 无 hero 图时转纯排版：大字 + 段落 + 按钮，右侧留白或放浅灰几何底 |
| 数字信任条 | site.extra.stats（数组：数值 + 说明），逐条对应 facts.md | 缺来源数字即整条省略，不放占位数 |
| 交替分栏 | site.extra 的介绍、优势文本 + images/ 实拍 | 无图改全宽文本列；文本缺失整段省略 |
| 照片连排条 | images/ 工厂车间实拍 | 少于 3 张改单张或省略；不放生图凑数 |
| 全出血氛围带 | 1 张横幅图 + 一句话 | 无图整条省略；生图可用但记来源 |
| 编号步骤行 | site.extra.steps 或正文 | 数据缺失整段省略 |
| 证书墙 | images/ 证书实拍 | 无证书改用资质文本列表（soft 底色段） |

条件渲染写法：`{% if site.extra.stats %}…{% endif %}`、`{% if item.cover %}…{% endif %}`，空区块不渲染空壳。

## 字体策略（标题衬线化）

中文品牌站的高级感来自"标题衬线 + 正文黑体"混排。规则禁的是外部 URL 字体，**可商用字体文件子集化后自托管进 theme/assets/ 是合规路径**：

1. 选可商用字体（推荐思源宋体 Bold，SIL OFL 1.1；来源 adobe-fonts/source-han-serif）。
2. 收集站点全部用字：site.json、columns.json、content/、theme/ 模板，**加 tools/yz.mjs 源码里的字符**（表单标签、隐私文案、日期格式等内置片段的字在里面）。
3. `pyftsubset 字体.otf --text-file=charset.txt --flavor=woff2 --output-file=xx.woff2 --layout-features='*' --no-hinting`，输出约 100–300KB。
4. woff2 放 theme/assets/，CSS 写 `@font-face`（font-display:swap），标题、品牌名、大数字用衬线，正文保持系统黑体；缺字回退系统宋体。
5. **内容更新后重跑子集**，否则新字会回退成系统字体。把子集文件名和重跑要求记入该站风格卡。

## 图片统一后期（消除拼贴感）

站内图片若来自不同来源（客户手册、网络图、生图），色调不一致会产生拼贴感。建站时对 `images/` 做一次统一调色，**原图先备份到站点根目录 `images-original/`（不进公开目录）**：

- 配方起点：降饱和 0.88 → 对比 1.05 → 暖调 gamma LUT（warm=(1.03,1.0,0.95), gamma=0.96，轻微压暗高光）。PIL `point()` 需要**扁平 768 元素查找表**（三个 band 依次平铺），传嵌套 list 会报 TypeError。
- 先生成 5 张代表图的前后对比表人工确认（重点核对品牌色海报的红色是否被破坏），认可后再批量应用；导出 quality 88。
- 品牌色要求苛刻的素材（海报、logo 图）可以跳过调色，保持原样。

## 动效规范

- 只用 opacity 和 transform，不做位移超 12px 的夸张动画。
- 入场（块式 stagger）：`main > section` 进入视口时，区块**内部的子元素**（爆品卡、统计格、步骤行、三联图、门店格、卡片网格）逐个以 80ms 交错延迟出现（fade + 12px 上移，.55s）；`.wrap`/`.split` 布局壳递归穿透，`.posters/.stats/.steps/.trio/.stores/.cards/.grid/.rows/.row/.kv-list/.facts` 组合容器下钻一层取子元素。实现见 theme/assets/site.js（IntersectionObserver 一次性触发，入场完成后清除 transitionDelay 以免拖慢 hover 过渡）。
- JS 自托管为 theme/assets/site.js，页面无 JS 时内容正常显示（类只由 JS 添加）。
- hover：全局 0.2s 过渡；卡片图片 hover scale 1.03；按钮 hover 上移 1px。
- `prefers-reduced-motion: reduce` 时全部动效关闭。
- 出现频率克制：同一屏只动一次，不循环播放。

## 检查清单（design 会话自检）

- [ ] 全页除照片外是否只有黑白灰 + 一种强调色
- [ ] 是否只有两种字重
- [ ] 分区是否全部用发丝线，没有阴影卡片
- [ ] 相邻文字段落之间是否有节奏带或足够留白
- [ ] 无图、无数据时段落是否干净省略
- [ ] 列表页是否保持了信息密度
