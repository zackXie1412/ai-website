# 网站风格卡

本地持续维护，不随静态网站导出。基础模板用于启动制作，按客户需要调整。

- 客户希望传达的印象：待从现有资料和沟通提取
- 参考网站及喜欢的部分：暂无
- 配色、字体、间距、圆角：起始值见 theme/assets/site.css；按品牌调整
- 图片风格及使用边界：只使用客户采用或授权的素材
- 页面布局与组件偏好：由 AI 按内容决定
- 客户反馈与已采用调整：暂无

## 本站设计方案

写模板前先确定这一节；设计方向变化时更新它，日常微调只改 theme 并在反馈里记一笔。

- 版式与区块模式（首页、列表、详情、联系各页的区块安排）：待写
- 品牌色到 CSS 变量的映射（--ink、--accent 等）：待写
- 字体层级与间距：待写
- 组件清单（卡片、导航、按钮、表单的用法）：待写

每次修改记录影响后续设计的结论即可，不建立评分或审批流程。
