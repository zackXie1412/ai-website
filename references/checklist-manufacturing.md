# 资料清单 · 制造业

适用于生产型企业：机械设备、阀门泵管、五金配件、电子元器件、塑料橡胶制品、建材、化工原料、纺织面料等。贸易公司也可以用，没有工厂的跳过“实力”里的工厂部分。

## 怎么用

- **级别**：核心 = 优先查找的资料；建议 = 相关页面需要时采用；可选 = 按客户目标决定。都不是开工门槛。
- **怎么用**：先从现有资料提取。只询问影响当前任务的缺口，问题可适当合并；明确事实不重复确认。
- **重点**：公司名称、主营产品、目标客户、公开联系方式和语言通常影响网站结构；客户已给出时直接复用。型号、参数、图片按实际内容需要整理。
- 资料不足时省略相关展示；用户明确要求先看示例时采用示例模式。不要为了完成清单编造事实。
