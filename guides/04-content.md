# 内容维护

先读 [工作空间与命令](../references/commands.md)。明确内容所在栏目和稳定 id；编辑原 JSON，保留 id 和 slug。新资料追加本地事实来源，采用后的文字与图片更新到内容文件。图片替换保持资源路径有效，原始资料保留。

- 新增：`new <栏目> <slug> --title 标题`，再补正文、封面、分类文本、来源与需要的语言。
- 修改：直接编辑该条 JSON；规格写正文表格。不要把具体产品事实硬编码进模板。
- 隐藏/显示：`hide` / `show <栏目/slug>`，只修改 visible；不是上线/下线。
- 删除/恢复：`delete` 进入本地回收站，`undelete` 默认恢复为隐藏。不会自动删除引用图片，也不会自动清空回收站。

完成修改后 build、serve，看列表、详情和关联首页是否正确。需要交付时导出这一份 dist。编辑内容、隐藏或删除都不自动改变已有 dist，更不修改真实线上网站。

平台接入后，本地内容需与平台最新草稿同步；当前不伪造平台 ID、revision 或保存成功回执。跨对话时读取工作空间继续，不能依赖聊天记忆作为唯一来源。
